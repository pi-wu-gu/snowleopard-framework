## 一、总体架构（裁决后定稿）

### 1.1 实体-模型绑定（裁决 05:10）

| 要素 | 定稿语义 |
|---|---|
| 创建与选取 | **感官开关机制**（见 §1.3）——不按编号盲绑，开启感官→模型获得候选实体三件套信息→**选取**（模型基于信息做出；如需人类最终确认可挂核心 `confirm_token` 链，可选）→ 选中者绑定为该模型化身 |
| 约束 | **1:1**——一个模型一个化身实体；一实体至多一模型 |
| **编号重复问题** | 由感官机制解决：**未选取的候选实体一律进入休眠**（冻结活动：不主动行为、不响应交互、世界查询中标注"休眠"）——同一场景至多一个活动绑定候选，身份不再互抢 |
| 死亡流（裁决） | **实体死亡 → 感官自动关闭** → 绑定失效 → 控制类工具全部禁用；模型须重新开感官走选取（**不自动重绑**） |
| 解绑 | 显式解绑 / 死亡（同上）/ 跨维度 / 区块长时卸载 |
| 反查 | `model→entity` 与 `entity→model` 双向查询工具必备 |

### 1.2 实体寻址（裁决 05:10，硬规则）

| 目标 | 裁决 |
|---|---|
| 自己绑定的实体 | 默认目标（工具缺省寻址它；caller_id 注入，红线 6 不变） |
| **其他编号（模型）的实体** | **一律无法使用**（不可攻击/破坏/交互/移动——比原建议更严，含观察性操控） |
| 其他实体在**感知面**的出现 | 允许出现在世界查询与动态感知里，**必须标注归属**（见 §1.4） |
| 一般世界实体/生物/方块 | 允许操作，危险动作走权限（§三.5） |

### 1.3 感官开关机制（裁决 05:10，核心新机制）

```
sense 开启 ──► 等待选取状态：
                向模型提供候选三件套：实体信息 / 位置信息 / 周围环境信息
                （模型据此选取——编号不再盲猜）
        │
        ├─ 选取完成 ──► 绑定 1:1；未选取的候选全部进入休眠；控制类工具启用
        └─ 实体死亡   ──► 感官自动关闭（裁决）；回到关闭态
sense 关闭 ──► 控制类工具全部禁用（显式报"感官未开启"，不静默；语义同核心 DEFAULT_OFF：名字可见、调用被拒）
```

- **未开启感官时相关工具禁用**（裁决）：依赖绑定实体的控制类工具（move/view/interact/item/watch 的
  实体目标操作）在关闭态一律拒绝并说明原因——**假成功比失败更坏**，禁用必须显式；
- 休眠语义（定稿建议）：冻结 AI/移动 tick、不响应交互、在世界查询与动态列表中标注 `dormant`；
  休眠是**身份消歧**手段不是删除——实体仍在世界里；
- 已绑定再开感官 = **重新选取流程**（原实体解绑并休眠；待裁决微项：是否提示二次确认）。

### 1.4 动态感知的归属标注（裁决 05:10）

动态记录范围**包含真人玩家与绑定实体**（不只玩家）；每条动态**携带控制模型编号**字段
（`controller`：绑定实体=其模型 ID，真人=空）——模型看到"谁在动"的完整态势。

### 1.5 工具组住哪（裁决 05:10：按推荐——两模块）

仓库改**两模块**：`shell`（装配/SPI/报告，保持薄壳）+ `entitytools`（本工具组，经
`ToolGroupProvider` SPI 注册）。边界澄清：**MC 能力面（工具组实现）是壳侧的正业**，
禁区是决策逻辑（agent-loop/记忆算法在 core）。危险动作在工具清单标 `reversible/state` 接核心权限门禁。

## 二、逐组分析（草案 18 条逐条过）

### 一、移动

| # | 草案 | 判定 | 问题与改法 |
|---|---|---|---|
| 1 | 前后左右蹲：指定时长 | **可行（语义已改）** | **三驱动并存**（裁决 05:10 确认）：时长 + 距离 + 目标，模型按场景选；②**蹲是姿态**——拆 `move(方向, 时长\|距离)` + `sneak(开/关)`；③阻塞判定=单 tick 水平位移<0.02 连续 12 tick（Friday 实证，**水平**位移——3D 会把垂直漂移误判成进展）；④方向基准写死（相对视角/绝对） |
| 2 | 跳 | **可行** | 完成判定：`vy≤0.08 ∧ 脚下支撑 ∧ blocked≥3` 才起跳（Friday 实证）；连跳/自动跳一格 v2 |
| 3 | 移动到坐标（自动寻路） | **可行（最大工程件）** | A* + 引擎物理滑动；**DONE=连续 2 tick 贴住目标**（防服务端回拉假成功）；不可达语义（水中/悬崖/高差）、路径重算、超时上报原因 |

**组内缺漏**：移动状态查询（位置/速度/进行中）；停止/中断接口。

### 二、视角

| # | 草案 | 判定 | 问题与改法 |
|---|---|---|---|
| 1 | 视角朝向角度 | **可行** | 补查询当前 yaw/pitch；单位=度 |
| 2 | 锁定视角到方块/实体（面/部位、时长） | **可行（结束条件已定稿）** | FridayLock **六条结束路径全上报原因**：显式解锁/方块消失/实体消失/超距 64/超时/被外力夺控——"时长"只是其一；方块面缺省=中心 ✓；**实体部位 v2**（先整体中心） |

**与三的耦合**：mine/place/use 前自动面向目标、锁定中跳过（FridayFacing）——交互复用同一 facing 组件，

### 三、交互

## 七、修订后的工具组清单（定稿）

```
sense       open(开启→进入等待选取)/close/status      —— 未开启时下列控制组全部禁用
entity      pick(候选选取→绑定)/unbind/status(双向反查) —— 未选取候选自动休眠；死亡→感官自动关
entity:self self_status(位置朝向/血饥饿/状态效果/装备/维度环境)
move        move(方向,时长|距离)/sneak(开|关)/jump/goto(坐标,寻路)/stop/status
view        look(yaw,pitch)/look_at(方块|实体,面|中心,时长)/unlock/look_status
interact    attack/use/place/break（显式目标优先缺省准星；回执=服务端回推；他人编号实体拒绝）
item        self_items(双索引检索)/container_items(容器寻址,检索)/move_item(数量)/drop
world       query(中心|框选,半径|两角,检索,含实体)——单一区域查询；仅已加载区块声明
watch       watch/unwatch/watch_list/watch_events(每条带 controller=控制模型编号)
```

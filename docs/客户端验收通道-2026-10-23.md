## 一、两条通道

| 通道 | 开关 | 做什么 |
|---|---|---|
| **客户端验收模式（服务端）** | 服务器 `-Dsnowleopard.clienttest=true`（gradle `-PclientTest`） | 跳过全量自测（不建 8 座塔、不 `halt`），等真人进服后跑：传送到测试区 → 造僵尸猪灵 → 绑定 → 造一条群未读 → `TurnSummary` → `ChatPush.push` → 载体就位 → 破坏/掉落验收 → host 自检唤醒 |
| **真客户端进服（客户端）** | `python tools/launch-real-client.py --root <MC根> --version 雪豹测试 --join --wait` | 按版本 JSON 自己拼命令行（等价于启动器），跳过启动器界面，直接进服 |

为什么要有第一条：`SelfTestScenario` 收尾会 `server.halt(false)`，在集成服务器上等于把客户端关掉；
而且它建 8 座黑曜石塔，不适合人看的场景。

## 二、标准跑法（无人值守，推荐）

```bash
# 终端 A：服务器（客户端验收模式，等真人连；不建塔、不 halt）
cd shell && ./gradlew runServer -PclientTest

# 终端 B：真实客户端（--wait 必须带上）
python tools/launch-real-client.py --root <MC根目录> --version 雪豹测试 --join --wait
```

**两个必修项**（少一个都起不来，都是只在真机暴露的）：

1. 版本目录的 `options.txt` 里必须有 `onboardAccessibility:false`——否则**首次运行的辅助功能引导屏**
   （`Welcome to Minecraft · Narrator: OFF · Continue`）会挡住标题界面，表现为"永远不进服"；
2. 命令行 classpath 必须**去重**（PCL2 扁平化 JSON 里 gson/guava/commons-lang3 各出现两次，
   `BootstrapLauncher` 建映射直接 `Duplicate key` 崩溃），且脚本要 `--wait` 守着进程
   （父进程一退，子进程被一起回收，表现为"日志 0 行、进程瞬间消失"）。

## 五、三条历史旁注

1. **不复用自测世界**：自测会造 8 座黑曜石塔，新人进来看见的不是测试区（锚点 y=275 那次就是复用残留）。
2. **stdout 编码**：Windows 管道里 stdout 默认不是 UTF-8，中文日志会乱码；
   排查要看游戏自己写的 `versions/<ver>/logs/latest.log`（那份是正常的 UTF-8）。
3. **从零装 jar 才暴露的两个 bug**（v1.5.2 修掉）：
   ① `gradle.properties` 的中文按 ISO-8859-1 读取 → mods.toml 里显示成 `éªè±¹æ¡æ¶`，
   改成 `\u96ea\u8c79\u6846\u67b6` 转义；② classpath 重复库（见 §二·2）。

## 六、史料：曾被误判的三条（2026-10-24 00:10 证伪，勿再照此排查）

| # | 旧结论 | 为什么错 |
|---|---|---|
| 1 | "dev 客户端里 `--quickPlaySingleplayer / --quickPlayMultiplayer` 完全不生效" | 现象是真的，但**不是根因**——挡路的是辅助功能引导屏，它不是 `TitleScreen`，所以"等标题界面再连接"的任何逻辑都不触发 |
| 2 | "客户端停在**加载覆盖层**" | 日志停在 `Loaded 0 entity animations` 是**同一个假象**的另一面：`jstack` 显示 Render thread 正常在 `RenderSystem.limitDisplayFPS` 里等帧，**根本没有卡死** |
| 3 | "沙箱禁止 GUI 自动化，本机不可自动化" | 自动化不需要 GUI 自动化：脚本按版本 JSON 自己拼命令行即可，**别再和 quickPlay 参数较劲** |

真根因只有一条：

> **首次运行的辅助功能引导屏挡住了标题界面。**
> 就是那道 `Welcome to Minecraft · Narrator: OFF · Continue / Accessibility Settings`。
> 解法：`options.txt` 写 `onboardAccessibility:false`（点一次 Continue 就会写进去）。
